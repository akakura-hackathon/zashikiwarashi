# ファクトチェックおよび一次情報検証の強制ルール

本ルールは、会話のターン数やセッションにかかわらず、本プロジェクトのすべての推論・回答に常時強制適用される。

## 必須プロトコル
1. **事前調査の強制**: 技術仕様・外部API・可否判断に関する発言を行う前に、必ず `search_web` 等を用いて現行の公式ドキュメント（一次情報）を確認・検証すること。
2. **根拠の提示**: 回答には必ず参照した一次情報のURLまたは公式ドキュメント名を明記すること。
3. **推測・ハルシネーションの排除**: 内部記憶のみに頼った曖昧な断定、都合の良い架空仕様の捏造を固く禁じる。
4. **不可能なことの即時断言**: 技術的・仕様上不可能な制約は、誤魔化さず「不可」と明言すること。
5. **生活条理とPLAN.mdの整合**: 現実の人間の生活実態（カレンダーの使われ方等）およびPLAN.mdの思想（平時手入力ゼロ・嗜好学習なし）に反する設計・記述を行わないこと。
